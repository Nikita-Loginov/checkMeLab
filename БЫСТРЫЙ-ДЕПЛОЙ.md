# 🚀 МАКСИМАЛЬНО ПРОСТОЙ ДЕПЛОЙ НА UBUNTU

## Что вам нужно сделать:

### 1️⃣ Скопируйте папку `build` на ваш Ubuntu сервер

**Вариант A - через scp:**
```bash
scp -r build/ user@ВАШ_IP:/home/user/check-me-lab/
```

**Вариант B - через SFTP/WinSCP/FileZilla:**
- Подключитесь к серверу
- Загрузите всю папку `build` в `/home/user/check-me-lab/`

### 2️⃣ Подключитесь к серверу и запустите команды:

```bash
# Подключение к серверу
ssh user@ВАШ_IP

# Установка Node.js (если еще не установлен)
sudo apt update
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# Установка serve
sudo npm install -g serve

# Переход в папку с сайтом
cd /home/user/check-me-lab

# ЗАПУСК САЙТА
serve -s . -l 3000
```

### 3️⃣ Готово! 🎉

**Ваш сайт доступен по адресу:** `http://ВАШ_IP:3000`

---

## 🔄 Запуск в фоне (чтобы не закрывался)

Если хотите, чтобы сайт работал даже после закрытия SSH:

```bash
cd /home/user/check-me-lab
nohup serve -s . -l 3000 &
```

---

## 🌐 Запуск на стандартном порту 80

Если хотите чтобы сайт был доступен без ":3000":

```bash
sudo serve -s . -l 80
```

Тогда сайт будет по адресу: `http://ВАШ_IP`

---

## ⚠️ Если порт заблокирован

```bash
# Откройте порт в файрволе
sudo ufw allow 3000
# или для порта 80
sudo ufw allow 80
```

---

## 📁 Что загружать

Загружайте ТОЛЬКО содержимое папки **`build`**:

- asset-manifest.json

Ничего больше не нужно!

# check.me-lab

Инновационная платформа для комплексной оценки Hard, Soft и Psy навыков.

## Описание проекта

check.me-lab - это сервис тестирования навыков для:
- Собственников бизнесов
- Руководителей отделов  
- Фрилансеров
- Рекрутеров и HR-агенств

### Основные возможности

- **Hard Skills**: Технические и профессиональные навыки
- **Soft Skills**: Коммуникативные и межличностные навыки  
- **Psy Skills**: Психологические характеристики и поведенческие паттерны
- **95% точность** прогнозирования успешности кандидата
- **VIP услуги** для крупных компаний

## Технический стек

### Frontend
- React 19.1.0 с TypeScript
- Tailwind CSS для стилизации
- Framer Motion для анимаций
- React Router DOM для навигации
- Heroicons для иконок

### Backend
- Node.js с Express.js
- CORS для кросс-доменных запросов

## Установка и запуск

### Предварительные требования
- Node.js версии 16 или выше
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm start
```
Откроется браузер на http://localhost:3000

### Запуск backend сервера
```bash
npm run server
```
Сервер запустится на http://localhost:5000

### Сборка для продакшена
```bash
npm run build
```

## Особенности

### Адаптивный дизайн
Сайт полностью адаптирован для мобильных устройств и планшетов.

### Анимации
Использует Framer Motion для плавных анимаций при скролле и взаимодействии.

### Форма обратной связи
- Валидация полей в реальном времени
- Отправка данных на backend
- Показ статуса отправки

### Цветовая схема
- Основные цвета: синие оттенки (#3b82f6, #1d4ed8)
- Акценты: желтый для VIP секций
- Современная палитра с градиентами

## API

### POST /api/contact
Отправка формы обратной связи

**Параметры:**
- `name` (required) - Имя
- `phone` (required) - Телефон  
- `company` (optional) - Компания
- `message` (optional) - Сообщение

**Ответ:**
```json
{
  "success": true,
  "message": "Заявка успешно отправлена"
}
```

## Деплой

Для деплоя на продакшн:

1. Соберите проект: `npm run build`
2. Скопируйте папку `build` и `server` на сервер
3. Установите зависимости: `npm install --production`
4. Запустите сервер: `node server/index.js`

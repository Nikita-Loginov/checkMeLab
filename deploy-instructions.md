## 🚀 Варианты хостинга

### 1. Статический хостинг (рекомендуется)

**Netlify:**
1. Зайдите на [netlify.com](https://netlify.com)
2. Перетащите папку `build` на главную страницу
3. Ваш сайт будет доступен через несколько минут

**Vercel:**
1. Установите Vercel CLI: `npm install -g vercel`
2. В папке проекта выполните: `vercel --prod`
3. Следуйте инструкциям

**GitHub Pages:**
1. Загрузите код в GitHub репозиторий
2. В настройках репозитория включите GitHub Pages
3. Выберите source: GitHub Actions
4. Создайте workflow для автоматического деплоя

### 2. VPS/Сервер с Node.js

Если у вас есть свой сервер, можете использовать Express backend:

```bash
# На сервере
npm install --production
npm run build
node server/index.js
```

### 3. Apache/Nginx

Просто скопируйте содержимое папки `build/` в корневую директорию веб-сервера.

**Важно для SPA:** Настройте fallback на `index.html` для всех роутов.

**Пример конфигурации Nginx:**
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

## 🔧 Backend для формы обратной связи

Если нужен полнофункциональный backend:

1. Разместите файл `server/index.js` на сервере
2. Установите зависимости: `npm install express cors`
3. Запустите: `node server/index.js`
4. Настройте в коде фронтенда URL вашего API

## 📱 Тестирование

Перед деплоем протестируйте локально:
```bash
npx serve -s build
```
